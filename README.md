# TUNIVERSE 🎧

**TUNIVERSE** is a simple web-based music streaming application built using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

---

## 💻 Tech Stack
- HTML + CSS + Bootstrap
- JavaScript
- PHP
- MySQL (XAMPP)

---

## 🚀 Features
- User Authentication (Login/Signup)
- Music Player with:
  - Play/Pause
  - Volume control
  - Like button
  - Song title and artist display
- Responsive UI
